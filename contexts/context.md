# MBTItest 项目上下文

## 项目定位
MBTI 性格测试 Web 应用，基于 Vue 3 + TypeScript + Vite 构建。

## 核心功能
- MBTI 93 题完整测试
- 实时计算性格类型结果
- 响应式设计，支持移动端

## 技术栈
- **前端**: Vue 3 + TypeScript + Vite
- **样式**: Tailwind CSS
- **部署**: GitHub Pages
